## מסך 1: דף נחיתה / Welcome

```
צור מסך נחיתה (Landing Page) לאפליקציה בשם "תביעה ביום" — סוכן AI של ביטוח לאומי לליווי מבוטחים בהגשת תביעת נכות.

מבנה:
1. HERO SECTION:
   - כותרת: "תביעה ביום — הגשת תביעת נכות בליווי סוכן AI"
   - תת-כותרת: "מהזימון ועד הוועדה — אנחנו מלווים אותך בכל שלב"
   - כפתור CTA: "בוא נתחיל →" (כחול, בולט, מונפש)
   - רקע: gradient כחול-כהה → כחול-בהיר → זהב

2. VALUE PROPS (3 כרטיסים):
   - "צ'קליסט חכם" — "יודעים בדיוק מה צריך — חובה, כדאי, רשות"
   - "מילוי טופס מונחה" — "טופס BL/283 אמיתי, שלב אחר שלב"
   - "הערכת סיכויים" — "ציון מוכנות 0-100 בזמן אמת"

3. SOCIAL PROOF:
   - "מבוסס על ניתוח 3,934 תיקים | 140 אבחנות | 286 מסמכים במסלול ירוק"

4. HOW IT WORKS (7 שלבים ויזואליים):
   זיהוי → צ'קליסט → השגה → העלאה → טופס → הערכה → הכנה

5. FOOTER: "ביטוח לאומי | מופעל ע״י Amazon Bedrock | הצהרת נגישות"

סגנון: מקצועי, חם, מזמין. לא ממשלתי-קר. כמו אפליקציית fintech ישראלית.
```

## מסך 2: שלב הזיהוי (Onboarding)

```
צור מסך "זיהוי לקות" — השלב הראשון שהמבוטח רואה אחרי Welcome.

מבנה:
1. HEADER: 
   - step indicator (7 נקודות, הראשונה פעילה)
   - "שלב 1 מתוך 7 — זיהוי"

2. AGENT GREETING (בועת צ'אט):
   - אווטר: 🤖 עם רקע כחול
   - טקסט: "שלום! אני נועם. ספר לי — מה הבעיה הרפואית שלך?"

3. QUICK REPLIES (כפתורי בחירה מהירה):
   - 6 כפתורים בגריד 2×3:
     🦴 כאבי גב | 💉 סוכרת | ❤️ לב
     🧠 נפשי | 👶 ילד נכה | 🎖️ נפגע איבה

4. TEXT INPUT:
   - placeholder: "או תאר בשפה חופשית..."
   - כפתור שליחה עגול

5. BOTTOM NOTE: 
   - "🔒 המידע שלך מוגן | נגיש ב-3 שפות"

סגנון: ממוקד, לא עמוס. תחושת שיחה אישית. רקע בהיר.
```

## מסך 3: צ'קליסט מותאם אישית

```
צור מסך "צ'קליסט מסמכים" שמופיע אחרי שהסוכן זיהה את הלקות (לדוגמה: סוכרת).

מבנה:
1. HEADER:
   - step indicator (שלב 2 פעיל)
   - "הצ'קליסט שלך — סוכרת (נכות כללית)"
   - badge: "על בסיס ניתוח 778 תיקים דומים"

2. PROGRESS BAR:
   - "3 מתוך 7 מסמכי חובה" | אחוזים | צבע דינמי (אדום→צהוב→ירוק)

3. DOCUMENTS LIST (3 קבוצות):
   🔴 חובה — בלי זה לא יטפלו (5 פריטים):
     ☐ סיכום מאנדוקרינולוג ← "מרפאת הקופה"
     ☐ בדיקת HbA1c ← "מעבדה" 🟢
     ☐ טופס תביעה BL/283
     ☐ רשימת תרופות
     ☐ צילום ת.ז.

   🟡 מומלץ — מחזק משמעותית (3 פריטים):
     ☐ בדיקת עיניים (רטינופתיה)
     ☐ בדיקת כליות
     ☐ יומן סוכר 3 חודשים

   🔵 רשות (2 פריטים):
     ☐ חוות דעת פרטית
     ☐ דוח סוציאלי

4. GREEN PATH BADGE:
   - "🟢 מסלול ירוק: 3 מסמכים אובייקטיביים — אישור מהיר"

5. ACTION BUTTONS:
   - "🔍 איך משיגים?" | "📤 העלאת מסמך" | "📝 מילוי טופס"

6. LIVE COUNTER (תחתון, sticky):
   - ציון מוכנות: 42/100 (מתעדכן בזמן אמת כשמסמנים)

סגנון: checkbox interactivi, progress bar מונפש, כל פריט clickable עם expansion.
כשמסמנים checkbox → אנימציית ✓ + progress bar מתעדכן + toast "נהדר! עוד 4 חסרים"
```

## מסך 4: השגת מסמכים (Guide)

```
צור מסך "תוכנית פעולה להשגת מסמכים" — הנחיה אישית איפה ומה להשיג.

מבנה:
1. HEADER:
   - step indicator (שלב 3)
   - "⚠️ חסרים לך 4 מסמכי חובה"

2. ACTION PLAN (3 צעדים — timeline/stepper):
   צעד 1: 👨‍⚕️ רופא משפחה
   - "קבע תור ← בקש: הפניות + מכתב + רשימת תרופות"
   - tip: "אמור: 'אני מגיש לוועדה — צריך סיכום מפורט'"
   - כפתור: "📅 קבע תור"

   צעד 2: 🏥 רופא מומחה
   - "עבורך: אנדוקרינולוג"
   - "בקש: סיכום עם אבחנות + מגבלות"
   - "⚠️ ודא: מ-6 חודשים אחרונים!"
   - כפתור: "📅 קבע תור"

   צעד 3: 🔬 בדיקות
   - "HbA1c — מעבדת הקופה (הפניה מרופא משפחה)"
   - "תוצאות: 1-3 ימים"
   - 🟢 "מסלול ירוק — אישור אוטומטי"

3. HMO QUICK LINKS (4 כפתורים):
   כללית *2700 | מכבי *3555 | מאוחדת *3833 | לאומית *507

4. TIMELINE:
   - "⏱️ תכנן 3-4 שבועות לפני הוועדה"

סגנון: Timeline/Stepper ויזואלי, כרטיסים לכל צעד, כפתורי פעולה בולטים.
```

## מסך 5: העלאת מסמכים + OCR

```
צור מסך "העלאת מסמכים" עם סריקה אוטומטית.

מבנה:
1. HEADER: step indicator (שלב 4) + "העלאה וסריקה"

2. UPLOAD ZONE:
   - Drag & drop area גדול (מרכזי, עם border dashed)
   - אייקון: 📤 + "גרור מסמך לכאן או לחץ לצילום"
   - כפתור: "📷 צלם מסמך" + "📁 בחר קובץ"

3. SCANNING ANIMATION (כשמעלים):
   - Progress bar + "🔎 סורק... מזהה סוג מסמך..."
   - אנימציית סריקה (קו שנע מלמעלה למטה)

4. RESULT CARD (אחרי סריקה):
   ┌─────────────────────────────┐
   │ 📄 בדיקות דם — ספירה + כימיה │
   │ ✅ תקין — תאריך מאי 2026     │
   │ 📋 מתאים: "בדיקות דם עדכניות" │
   │ 🟢 מסלול ירוק — אישור מהיר   │
   └─────────────────────────────┘

   או:
   ┌─────────────────────────────┐
   │ 📄 סיכום אורתופד             │
   │ ⚠️ תאריך ישן (8 חודשים)      │
   │ 💡 "מומלץ לבקש סיכום חדש"    │
   └─────────────────────────────┘

5. UPLOADED LIST:
   - רשימת מסמכים שהועלו עם סטטוס (✅/⚠️/❌)
   - progress: "3/5 מסמכי חובה הועלו"

6. NEXT: "📝 המשך למילוי טופס"

סגנון: drag-and-drop מודרני, אנימציית סריקה, results cards עם צבעי סטטוס.
```

## מסך 6: מילוי טופס BL/283

```
צור מסך "מילוי טופס תביעה" — ממשק שיחתי למילוי טופס BL/283.

מבנה:
1. HEADER: step indicator (שלב 5) + "טופס BL/283 — תביעה לקביעת דרגת נכות"

2. FORM PROGRESS:
   - "שלב 7 מתוך 12" + progress bar

3. CHAT-STYLE FORM:
   - Agent שואל: "מה הכתובת שלך?"
   - User עונה → agent ממלא ומאשר
   - tip bubbles: "💡 מגבלות יום-יומיות — זה מה שקובע!"

4. FORM PREVIEW (sidebar או drawer):
   - תצוגה מקדימה של הטופס המלא
   - שדות שמולאו = ירוק, חסרים = אפור

5. COMPLETION:
   - "🎉 הטופס מוכן!" + confetti animation
   - כפתורים: "📋 העתק" | "🖨️ הדפס" | "📤 הגש דיגיטלי"
   - תצוגה מקדימה מלאה של הטופס

סגנון: שיחתי (conversational form), לא טופס קלאסי. כל שאלה = בועה.
Progress bar מתקדם עם כל תשובה. Celebration animation בסוף.
```

## מסך 7: הערכת סיכויים

```
צור מסך "הערכת סיכויים" — dashboard אישי עם ציון מוכנות.

מבנה:
1. HEADER: step indicator (שלב 6)

2. SCORE CIRCLE (מרכזי, גדול):
   - ציון: 72/100
   - צבע: ירוק (>70) / צהוב (40-70) / אדום (<40)
   - אנימציית counter-up
   - טקסט מתחת: "מוכנות בינונית-גבוהה"

3. BREAKDOWN (3 מדדים):
   - מסמכי חובה: 5/7 ✓ (progress bar)
   - טופס תביעה: ✅ מולא
   - מסלול ירוק: 3 מסמכים אושרו

4. RECOMMENDATIONS (cards):
   - "📍 השג HbA1c — יעלה ציון ב-12 נקודות"
   - "📍 עדכן סיכום אנדוקרינולוג — +8 נקודות"

5. COMPARISON:
   - "מבוטחים דומים: 87% שהגיעו עם ציון 80+ קיבלו אישור"

6. CTA: "🎯 מוכן? המשך להכנה לוועדה"

סגנון: Dashboard clean, ציון מרכזי בולט, cards עם actionable recommendations.
אנימציית gauge/circle שמתמלא.
```

## מסך 8: הכנה לוועדה

```
צור מסך "הכנה לוועדה" — יעוץ אחרון לפני הוועדה.

מבנה:
1. HEADER: step indicator (שלב 7) + "🏛️ מוכן לוועדה!"

2. TIMELINE (יום לפני / ביום / בוועדה):
   📅 יום לפני:
   - סדר מסמכים בתיקייה שקופה
   - הכן רשימת תרופות
   - כתוב 3 משפטים על היום-יום

   🏥 ביום:
   - הגע 15 דקות לפני
   - קח מלווה + ת.ז. + מסמכים
   
   🗣️ בוועדה:
   - דבר על יום-יום, לא אבחנות
   - "לא יכול..." > "יש לי..."
   - בקש פרוטוקול

3. DO / DON'T (שני עמודות):
   ✅ DO: תאר בכנות, בקש פרוטוקול, הביא מלווה
   ❌ DON'T: לא לחתום על מה שלא מבין, לא להגיד "הכל בסדר"

4. SIMULATION CARD:
   - "הרופא ישאל: 'מה מפריע לך?'"
   - "ענה: 'אני לא מצליח לעלות מדרגות / לישון / לעבוד...'"

5. RIGHTS ACCORDION:
   - מלווה | תרגום | פרוטוקול | ערעור 60 יום | נגישות

6. CTA: "💪 בהצלחה! אני כאן אם צריך"

סגנון: חם ומעודד. Timeline ויזואלי. Do/Don't עם icons.
הרגשה של "אתה מוכן, הכל בסדר".
```

