## 1. הרעיון

### "נועם" — סוכן AI שמלווה מבוטחים לוועדה רפואית

סוכן AI בשם **"נועם"** שמלווה מבוטחים מרגע קבלת זימון לוועדה רפואית ועד ההגעה מוכנים ומצוידים בכל המסמכים הנדרשים.

### הבעיה שאנחנו פותרים

| הבעיה | המציאות היום |
|--------|-------------|
| תיקים חסרים | מבוטחים מגיעים לוועדה בלי מסמכים קריטיים |
| חוסר ידע | לא יודעים מה הזכויות שלהם |
| טפסים מורכבים | לא מבינים את הטפסים ואיך למלא אותם |
| עומס על נציגים | אלפי שיחות טלפון לבירור מידע בסיסי |

### הבסיס — מאגר ידע ארגוני

- **3,934** רשומות אבחנה-מסמך
- **140** קבוצות אבחנות
- **7** תחומי תביעה
- **286** מסמכים מדורגי AI (מסלול ירוק)

## 2. מה נבנה (MVP)

### רכיבי הליבה

| רכיב | תיאור |
|-------|--------|
| 🗣️ סוכן שיחה חכם (NLU) | המבוטח מתאר בשפה חופשית את מצבו ומקבל מענה מותאם אישית |
| ✅ צ'קליסט מסמכים אינטראקטיבי | חובה / מומלץ / אופציונלי עם מעקב התקדמות (progress) |
| 📝 מילוי טופס תביעה מונחה | 9 שלבים, מבוסס על טופס אמיתי של בטל"א |
| 📊 הערכת מוכנות | ציון 0-100 עם המלצות ממוקדות |
| 🔗 סיוע במציאת מסמכים | קישורים לקופות חולים, הפניות, קביעת תורים |
| 🟢 מסלול ירוק | זיהוי אוטומטי של מסמכים אובייקטיביים — אישור מהיר |
| ⚖️ מיצוי זכויות | הסבר מותאם לסוג הוועדה והתביעה |

### תרחיש שימוש טיפוסי

```
מבוטח: "יש לי סוכרת ובעיות גב, קיבלתי זימון לוועדה"
נועם: → מזהה אבחנות → בונה צ'קליסט מותאם → מנחה מילוי טופס → מעריך מוכנות
```

## 3. ארכיטקטורה טכנית

### תרשים רמה גבוהה

```
┌─────────────────────────────────────────────────────────┐
│                    Frontend (React)                       │
│  React 18 + TypeScript + Vite + Tailwind + shadcn/ui    │
└─────────────────────┬───────────────────────────────────┘
                      │ HTTPS
┌─────────────────────▼───────────────────────────────────┐
│              Amazon API Gateway                          │
└─────────────────────┬───────────────────────────────────┘
                      │
┌─────────────────────▼───────────────────────────────────┐
│           Amazon Bedrock Agent (Claude)                   │
│  ┌──────────────┐  ┌──────────────────────────────┐     │
│  │ Action Groups │  │ Knowledge Base                │     │
│  │ (Lambda)      │  │ S3 + OpenSearch Serverless   │     │
│  └──────────────┘  └──────────────────────────────┘     │
└─────────────────────────────────────────────────────────┘
```

### סטאק טכנולוגי

| שכבה | טכנולוגיה |
|-------|-----------|
| Frontend | React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui |
| AI Engine | Amazon Bedrock Agent (Claude) |
| Knowledge Base | Amazon S3 + OpenSearch Serverless |
| Backend | API Gateway + AWS Lambda (Action Groups) |
| Deploy (MVP) | GitHub Pages |
| Deploy (Production) | AWS Amplify |

### Action Groups — Lambda Functions

1. **getDocumentChecklist** — מחזיר צ'קליסט מותאם לאבחנה
2. **assessReadiness** — מחשב ציון מוכנות
3. **getGreenPathDocs** — מזהה מסמכים במסלול ירוק
4. **getRightsInfo** — מחזיר מידע על זכויות לפי סוג ועדה
5. **getFormGuidance** — מנחה מילוי טופס שלב-אחר-שלב

## 6. מספרי אימפקט

### נתוני המאגר

| מדד | ערך |
|------|-----|

### הערכת אימפקט

| מדד | לפני | אחרי | שיפור |
|------|-------|-------|--------|
| מבוטחים עם תיק חסר | 72% | ~5% | **↓ 93%** |
| זמן ממוצע לנציג | 15 דק' | 3 דק' | **↓ 80%** |
| שיחות טלפון לבירור | אלפים/חודש | מאות/חודש | **↓ 70%** |
| זמן הכנה למבוטח | שעות (אם בכלל) | 20 דק' מונחות | **שיפור דרמטי** |

### חיסכון מצטבר

- ~15 דקות לנציג × אלפי פניות = **אלפי שעות עבודה בחודש**
- הפחתת דחיות ועדה בגלל מסמכים חסרים
- שיפור שביעות רצון מבוטחים
